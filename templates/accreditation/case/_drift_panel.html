What this checks

Each stage of an open case should have exactly one task, sitting with the person who must act. “Drift” is when the two no longer match: a task left behind after its stage finished, or a stage that has no task at all.

{% icon "alert" 18 "2.2" %}

Why it matters

A stage without a task means nobody is told to act, so the case silently stalls. A left-over task clutters someone's inbox with work that is already done.

{% icon "check" 18 "2.4" %}

What to do

Usually nothing: the check runs every night and repairs tasks by itself. Only People to review needs a person — the system never changes someone's eligibility on its own.

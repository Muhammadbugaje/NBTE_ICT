Import institutions and programmes

Download the template, fill it in, and upload it. The whole sheet is checked first — one bad row rejects the batch and nothing is changed. A valid sheet waits for a second officer, then is applied in one go. Rows update existing records by code (or name); nothing is ever duplicated.

Rules

  1. New institutions are always created as proposed, handled by NTIRD.
  2. Status cannot be changed by import — use the actions (approve, delist …).
  3. Matching: code first, then exact name; a category change on an approved institution moves it to the category's department.
  4. Re-importing an unchanged export changes nothing.

Migrate from the previous system

For institutions that already exist in the previous system. Choose Migrate from the previous system and upload the migration template (institutions, programmes and, optionally, past accreditation decisions).

  1. Institutions are created approved in their handling department — no onboarding application.
  2. Programmes keep their status, approval type, streams and dates; a blank expiry is worked out from the approval type.
  3. Portal administrators are created inactive; they get a set-password link when you choose.
  4. Running the same workbook again changes nothing.

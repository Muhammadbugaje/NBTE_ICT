Formulas

Fees and other computed values. Each is checked against a safe allow-list when saved, and every bill keeps a snapshot of the formula it used — so a change here never alters an issued bill.

What can a formula contain?

Numbers, text in quotes, the variables listed on each formula, + - * / // %, ** (exponent up to 4), comparisons, and / or / not, x if condition else y, and the functions min max round ceil floor abs clamp. cfg('qa.some.key') reads another setting. Nothing else is allowed — no attribute access, imports or code.

Example: programmes * (2000000 if ownership == 'private' else 1000000)

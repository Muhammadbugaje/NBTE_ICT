{% icon "upload" 28 %} Up to 25 MB · e.g. NBTE_Facilities_and_Equipment_Import.xlsx

What the file needs

  • A sheet Facilities & Equipment with one row per item: Programme, Levels, Facility code, Facility, Group / sub-heading, Equipment, ND qty, HND qty, Remarks, Critical (Y/N), Sort order.
  • An optional Programmes sheet with each programme's levels, source curricula and notes.
  • Rows are matched on Programme + Facility + Group + Equipment, ignoring capitals and spaces — so importing the same file twice changes nothing.
  • Programme names are matched to the national programme list exactly, by alias, or by the closest similar name; you confirm each one that is not an exact match.
  • Nothing is deleted. Items missing from the file are kept unless you choose to mark them inactive.

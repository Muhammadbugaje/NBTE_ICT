Recommended import order for a fresh database

The simplest route is one file: Export everything here, then import that single workbook on the new database; it loads every sheet in this order by itself. If you move the categories one by one, import them in this order. Each later step can point back at rows loaded by an earlier one.

  1. 0Prepare the new databasePoint the system at it, run python manage.py migrate, create your own administrator with createsuperuser, sign in and open this page.

    3. {% endfor %}
  3. {% icon "check" 14 "2.6" %}After the importEvery imported person must set a new password at first sign-in. With password hashes in the file they sign in with their old password; otherwise with the default password you give on the import form. Copy the media folder too if you want photos, logos and signatures (asset photos and attachments travel only as file paths: copy the protected media folder for those). Importing a file twice is safe: rows are matched and updated, never duplicated, and nothing is deleted.

Export with passwords (optional)

{% icon "alert" 16 %}Only for moving to a new database. Adds every user's Django password hash (never the password itself) to the Users sheet so old passwords keep working after the import. Anyone holding the file can try to crack the hashes: keep it secret, move it securely and delete it afterwards. Off by default.
